Pennsylvania Cities With Circle Markers

Harrisburg and Lancaster plotted with proportional circle markers, with population data surfaced through interactive tooltips.

Leaflet JavaScript HTML/CSS Esri Basemap

Overview

What this map shows

This map compares two Pennsylvania cities, Harrisburg and Lancaster, using circle markers sized to represent relative population. It's a small-scale exercise in proportional symbol mapping: rather than just placing pins, the size of each circle itself carries information.

Approach

Data & method

Built from scratch with the Leaflet JavaScript library rather than a no-code map builder, which meant writing the marker logic, tooltip behavior, and styling directly.

  • City coordinates and population figures encoded directly as map data
  • Circle marker radius scaled relative to each city's population
  • Interactive tooltips reveal population details on hover or tap
  • Topographic basemap sourced from Esri for geographic context
