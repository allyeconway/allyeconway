Proportional Map of Population in Amsterdam

Population distribution across Amsterdam shown through proportional symbols, with per-region totals available on click.

ArcGIS Maps SDK for JavaScript Hosted Feature Service Esri Basemap

Overview

What this map shows

This map shows how population is distributed across Amsterdam using proportional symbols: larger circles mean more people. Each circle has an attached popup that states the exact total population for that region, so the visual comparison is always backed by an exact number.

Approach

Data & method

Built with the ArcGIS Maps SDK for JavaScript, pulling population figures from a hosted ArcGIS Feature Service and mapping them to circle size, with an Esri basemap underneath for geographic context.

  • Population data sourced from an ArcGIS Feature Service
  • Circle size scaled proportionally to total population
  • Popups surface the exact population figure per region
