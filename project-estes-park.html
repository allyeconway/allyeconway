Trail Map of Scenic Hikes in Estes Park, CO

A reference map built for on-trail planning, pulling together a hand-picked set of scenic hikes around Estes Park into a single printable layout.

ArcGIS Pro PDF Export Cartographic Design

Overview

What this map shows

This project set out to answer a simple question for hikers visiting Estes Park: which trails are worth the drive, and how do they compare to each other at a glance? Rather than a general-purpose basemap, the map is scoped tightly to a curated list of scenic hikes, so it reads more like a printed trail guide than a full regional atlas.

Approach

Data & method

The map was built in ArcGIS Pro and exported as a print-ready PDF, which meant paying close attention to label placement, symbol hierarchy, and legend design since the final product has no interactivity to fall back on.

  • Trail geometry and elevation context sourced from public GIS layers for the Estes Park area
  • Symbology designed for print legibility: trailheads, difficulty tiers, and named peaks each get distinct markers
  • Final layout composed as a standalone reference sheet rather than a web map
