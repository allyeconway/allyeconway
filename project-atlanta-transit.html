Transit Commuters by Census Tract in Atlanta, GA

Census-tract level transit ridership for Atlanta, pulled directly from the Census API and mapped in R.

R tidycensus ggplot2

Overview

What this map shows

This map looks at transit commuting patterns across Atlanta at the census tract level. Instead of working from a pre-packaged shapefile, the underlying data was pulled directly from the Census Bureau via R, keeping the whole workflow, from data pull to final map, inside a single script.

Approach

Data & method

Built entirely in R using the tidycensus package, which handles authentication and querying against the Census API and returns tract-level geometry ready to map.

  • Commuting-by-transit estimates pulled via tidycensus from Census API data
  • Tract-level geometries joined directly to the commuting estimates
  • Final map rendered and exported as a static PDF
