Project 2

Pennsylvania Cities With Circle Markers

This map displays Harrisburg and Lancaster in PA. Circle markers are used to represent their locations and relative areas. The data is based on their latitude and longitude and includes basic population information shown through interactive tooltips. The map was created using HTML, CSS, and JavaScript with the Leaflet library, and uses a topographic basemap from Esri.

Project 3

Philly PPR Program Sites

This map highlights the Frank Glavin Playground. This location is a part of the Philadelphia Parks & Recreation GeoJSON dataset. The data was filtered to show only the above mentioned park, which was then visualized as a styled circle marker on the map. The web map was created using HTML, CSS, and JavaScript with the Leaflet library and a basemap from Mapbox.

Project 4

Proportional Map of Alternative Energy Sources

This proportional symbol map depicts alternative energy power plants across the U.S., displaying their location and generation capacity. The data is sourced from a GeoJSON dataset of power plants, with circle marker sizes scaled based on megawatt capacity and filtered by energy type (Biomass, Geothermal, and Solar). Again, this map was created using HTML, CSS, and JavaScript with the Leaflet library, and uses a dark themed basemap from CartoDB.

Project 5

Choropleth Map of Crime Incidents Occurring in SF at Night

This choropleth map visualizes nighttime crime incidents across San Francisco by census block group using a hosted ArcGIS Feature Service for the dataset. Crime counts are symbolized on a color gradient with darker blocks representing areas with more recorded incidents. Lighter block groups have less recorded night time crime incidents. Upon selecting a block group a popup appears that gives the exact amount of nighttime crimes occurring in that area. A legend of different crime thresholds was also included. The map was developed using ArcGIS Maps SDK for JavaScript.

Project 6

Proportional Map of Population in Amsterdam

This web map shows population distribution across Amsterdam using proportional symbols. The variation in circle size represents the total population of that location. Each circle also has a popup that states the total population of that region. The data for this map was sourced from ArcGIS Feature Service and developed using ArcGIS Maps SDK for JavaScript. The basemap is also gathered from Esri.
