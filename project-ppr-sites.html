Philly PPR Program Sites

Frank Glavin Playground isolated from Philadelphia's Parks & Recreation dataset and styled as a standalone marker.

Leaflet GeoJSON JavaScript Mapbox

Overview

What this map shows

Philadelphia Parks & Recreation publishes a GeoJSON dataset covering its full network of program sites. This project filters that dataset down to a single location, Frank Glavin Playground, and focuses the map experience entirely around it.

Approach

Data & method

The core of this exercise was working directly with a real municipal GeoJSON feed: filtering it down to the relevant feature, then restyling that single point as a clean, styled circle marker.

  • Source data: Philadelphia Parks & Recreation program sites GeoJSON
  • Dataset filtered in code down to the target site
  • Custom circle marker styling applied via Leaflet
  • Basemap tiles sourced from Mapbox
