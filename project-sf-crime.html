Choropleth Map of Nighttime Crime Incidents in San Francisco

Census block groups shaded by nighttime crime incident counts, with a click-through popup and a threshold legend.

ArcGIS Maps SDK for JavaScript Hosted Feature Service

Overview

What this map shows

This choropleth map visualizes nighttime crime incidents across San Francisco at the census block group level. Darker block groups indicate more recorded incidents; lighter ones indicate fewer. Clicking any block group opens a popup with the exact incident count for that area.

Approach

Data & method

Built on the ArcGIS Maps SDK for JavaScript against a hosted ArcGIS Feature Service, which handled the underlying crime data. The main design work was in the color ramp and the legend, so the thresholds read clearly without a data dictionary.

  • Data source: hosted ArcGIS Feature Service of nighttime crime incidents by block group
  • Color gradient symbology tied to incident count
  • Click-to-reveal popups with exact per-block-group counts
  • Legend built around defined crime-count thresholds
